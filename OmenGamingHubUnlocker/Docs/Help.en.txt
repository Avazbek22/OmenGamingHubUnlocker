This app helps you keep OMEN Gaming Hub under control.

It does not uninstall OMEN or remove drivers. It limits OMEN background startup and network access while preserving the original settings for recovery.

Menu guide:
 - Check status: shows the current state of every managed component.
 - Safety check (no changes): inspects the system and shows an exact action plan without changing anything.
 - Activate protection: applies the main protection profile.
 - Restore original settings: reverses the app's changes using the saved backup.
 - Reset OMEN and reapply protection: runs the Windows app reset and immediately restores protection.
 - Help: opens this page.
 - About: shows brief project information.
 - Change language: switches between English and Russian.

What Activate protection does:
 - Blocks network access for the current OMEN package and executables.
 - Sets OMEN services to Manual and stops them.
 - Disables and stops OMEN scheduled tasks.
 - Terminates active OMEN background processes.
 - Removes OMEN entries from registry startup.
 - Blocks known OMEN domains through the hosts file.
 - Rechecks the system to ensure background components stay stopped.

What Reset OMEN does:
 - Isolates OMEN from the network before the reset.
 - Runs the same app reset available in Windows Settings.
 - Clears OMEN's local app data.
 - Rediscovers the package and background components after the reset.
 - Reapplies and verifies protection.

Good to know:
 - Start with Check status or Safety check if this is your first time using the app.
 - Use Activate protection for normal operation.
 - If OMEN updated or stopped working, use Reset OMEN and reapply protection.
 - Use Restore original settings to reverse all managed changes.
 - Applying changes requires administrator access.
 - If elevation uses another account, the operation stops safely instead of changing the wrong user profile.
