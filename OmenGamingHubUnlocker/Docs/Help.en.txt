This tool helps you keep OMEN Gaming Hub under control.

It does not uninstall OMEN.
It does not remove your drivers.
It mainly changes startup behavior and network access for OMEN.

Menu guide:
 - Check status: shows what is active right now.
 - Dry run: preview only. It changes nothing.
 - Activate scripts: applies the main protection profile.
 - Disable scripts: removes this tool's blocks and restores saved startup settings.
 - Reset Omen Gaming Hub & Activate scripts: resets the OMEN app and immediately applies protection again.
 - Help: opens this page.
 - About: short project information.
 - Change language: switches between English and Russian.

What Activate scripts does:
 - Puts OMEN-related services into a safer startup mode.
 - Disables OMEN scheduled tasks.
 - Removes OMEN autostart entries from Run keys.
 - Adds Windows Firewall rules for OMEN executables.
 - Adds hosts-file blocks for known OMEN domains.

What Reset Omen Gaming Hub & Activate scripts does:
 - Closes OMEN-related processes.
 - Runs the same app reset that Windows Settings uses.
 - Clears the OMEN app data.
 - Immediately applies protection again after the reset.

Good to know:
 - Dry run is the safest first step if you just want to inspect.
 - Activate is the normal everyday option.
 - Reset is useful after an OMEN update or when OMEN gets stuck.
 - Disable is useful only if you want to undo this tool's changes.
 - Administrator rights are required for real changes.

Simple recommendation:
 - New user: start with Dry run or Check status.
 - Normal use: run Activate scripts.
 - OMEN updated or broke: run Reset Omen Gaming Hub & Activate scripts.
