Эта программа помогает держать OMEN Gaming Hub под контролем.

Она не удаляет OMEN.
Она не удаляет драйверы.
В основном она меняет автозапуск и сетевой доступ OMEN.

Описание меню:
 - Проверить статус: показывает, что сейчас активно.
 - Dry run: только предварительный просмотр. Ничего не меняет.
 - Активировать защиту: применяет основной профиль ограничений.
 - Отключить защиту: снимает блокировки программы и восстанавливает сохраненные настройки автозапуска.
 - Сбросить Omen Gaming Hub и активировать защиту: делает reset приложения OMEN и сразу снова применяет ограничения.
 - Справка: открывает эту страницу.
 - О программе: короткая информация о проекте.
 - Сменить язык: переключает английский и русский.

Что делает «Активировать защиту»:
 - Переводит службы OMEN в более безопасный режим запуска.
 - Отключает задачи планировщика OMEN.
 - Удаляет записи автозапуска OMEN из Run keys.
 - Добавляет правила Windows Firewall для исполняемых файлов OMEN.
 - Добавляет блокировки известных доменов OMEN в hosts.

Что делает «Сбросить Omen Gaming Hub и активировать защиту»:
 - Закрывает процессы OMEN.
 - Запускает тот же reset приложения, что и параметры Windows.
 - Очищает данные приложения OMEN.
 - Сразу после reset снова применяет защиту.

Что важно знать:
 - Dry run — самый безопасный первый шаг, если ты просто хочешь посмотреть состояние.
 - Активировать защиту — это обычный повседневный режим.
 - Reset полезен после обновления OMEN или если OMEN завис.
 - Отключить защиту нужно только если ты хочешь отменить изменения этой программы.
 - Для реальных изменений нужны права администратора.

Простая рекомендация:
 - Новый пользователь: начни с Dry run или проверки статуса.
 - Обычный сценарий: используй «Активировать защиту».
 - OMEN обновился или сломался: используй «Сбросить Omen Gaming Hub и активировать защиту».
