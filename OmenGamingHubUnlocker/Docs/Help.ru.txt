Эта программа помогает держать OMEN Gaming Hub под контролем.

Она не удаляет OMEN или драйверы. Программа ограничивает фоновый запуск и сетевой доступ OMEN, сохраняя исходные настройки для восстановления.

Описание меню:
 - Проверить статус: показывает текущее состояние всех компонентов.
 - Предварительная проверка (без изменений): анализирует систему и показывает точный план действий, ничего не меняя.
 - Активировать защиту: применяет основной профиль ограничений.
 - Восстановить исходные настройки: отменяет изменения программы с помощью сохранённой резервной копии.
 - Сбросить OMEN и заново применить защиту: сбрасывает приложение средствами Windows и сразу применяет защиту повторно.
 - Справка: открывает эту страницу.
 - О программе: показывает краткую информацию о проекте.
 - Сменить язык: переключает русский и английский языки.

Что делает «Активировать защиту»:
 - Блокирует сетевой доступ текущего пакета и исполняемых файлов OMEN.
 - Переводит службы OMEN на ручной запуск и останавливает их.
 - Отключает и останавливает задачи планировщика OMEN.
 - Завершает текущие фоновые процессы OMEN.
 - Удаляет записи OMEN из автозапуска реестра.
 - Блокирует известные домены OMEN через файл hosts.
 - Повторно проверяет систему, чтобы фоновые компоненты не запустились снова.

Что делает сброс OMEN:
 - Изолирует OMEN от сети до начала сброса.
 - Выполняет тот же сброс приложения, который доступен в параметрах Windows.
 - Очищает локальные данные приложения OMEN.
 - Заново находит пакет и фоновые компоненты после сброса.
 - Повторно применяет и проверяет защиту.

Что важно знать:
 - Для первого знакомства начните с проверки статуса или предварительной проверки без изменений.
 - Для обычного использования выберите «Активировать защиту».
 - Если OMEN обновился или перестал запускаться, используйте сброс с повторной защитой.
 - Чтобы полностью отменить изменения программы, восстановите исходные настройки.
 - Для применения изменений нужны права администратора.
 - Если повышение прав выполнено через другую учетную запись, операция безопасно остановится и не затронет чужой профиль.
