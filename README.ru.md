  Небольшая утилита для ноутбуков и десктопов <strong>HP OMEN</strong>.

Программа не удаляет OMEN Gaming Hub, а просто не даёт ему запускаться самому и обращаться к серверам HP раньше, чем нужно вам — например, до того, как вы включите VPN.
✅ Как это выглядит на практике:
Включаете компьютер
Включаете VPN (если он вам нужен)
Сами открываете OMEN Gaming Hub, когда готовы
...вместо того чтобы OMEN сам просыпался при загрузке Windows и связывался с серверами HP.
> 🧭 Если вы здесь из-за сообщения вроде **«OMEN Gaming Hub недоступен в вашем регионе»**, **«неверный регион»** или **«страна не поддерживается»**:
> Эта программа **не меняет** регион в Windows или Microsoft Store.
> Она не даёт OMEN запускаться самому и, по желанию, блокирует ему доступ в интернет — чтобы вы сначала включили VPN, а потом сами открыли OMEN.

🧰 Что делает "Activate scripts"
Блокирует доступ OMEN в интернет — правило файрвола не слетает после обновлений OMEN
Переводит фоновые службы OMEN в режим «Вручную» и останавливает уже запущенные
Отключает запланированные задачи OMEN и останавливает те, что уже выполняются
Завершает фоновые процессы OMEN
Убирает OMEN из автозагрузки Windows — исходные настройки сохраняются заранее, так что всё можно вернуть обратно
По желанию блокирует известные адреса серверов HP/OMEN
Дважды проверяет, что всё действительно осталось выключенным, прежде чем сообщить «готово»
Ваши прежние настройки всегда сохраняются перед любыми изменениями.

♻️ Что делает "Disable scripts"
Возвращает службы и задачи в точности в то состояние, в котором они были
Восстанавливает исходные записи автозагрузки Windows
Проверяет, что всё вернулось к норме, прежде чем снять блокировку сети
Удаляет только те правила файрвола и записи hosts, которые создала сама программа
Если что-то не удалось восстановить полностью, блокировка сети остаётся включённой — для безопасности

🧱 Правило файрвола переживает обновления OMEN
Обновления OMEN Gaming Hub (особенно через Microsoft Store) часто меняют пути к файлам и имена исполняемых файлов. Большинство простых блокировок в файрволе после такого обновления перестают работать — эта нет.
Основное правило привязано к идентификатору пакета OMEN в Store, а не к конкретному пути файла. При каждом запуске Activate программа также:
держит основное правило активным, пока проверяет новые пути к файлам
находит новые файлы OMEN и добавляет для них правила
удаляет устаревшие правила, которые больше не нужны
проверяет, что каждый текущий файл OMEN действительно заблокирован
Это закрывает разрыв, который раньше возникал между сбросом OMEN и обновлением правил файрвола.

🧩 Техническое описание (для разработчиков)
Язык: C#
Платформа: .NET 10
Тип приложения: консольное приложение (Windows 10/11), портативная однофайловая сборка
Повышение прав: манифест приложения запрашивает права администратора (UAC) при запуске
Основные операции:
управление службами через Windows API, с безопасными резервными вариантами при необходимости
отключение запланированных задач и завершение запущенных процессов
очистка записей автозагрузки (Run) в реестре в стандартных расположениях
правила файрвола по package-SID и по исполняемым файлам, с резервным вариантом через COM/PowerShell и проверкой после записи
атомарная запись hosts и файла отката с сохранением кодировки
проверка, что операции с AppX или HKCU выполняются от имени интерактивного пользователя
Интерфейс сделан предсказуемым:
Status = текущие факты
Dry run = что будет сделано (прогноз)
Activate/Disable = реальные изменения + финальный снимок состояния
Сборка релизных файлов
Скрипт сборки нужно запускать из чистой локальной ветки `main`, точно совпадающей с `origin/main`:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Publish-Release.ps1
```
Скрипт запускает тесты и собирает автономные однофайловые исполняемые файлы для `win-x64` и `win-arm64` в `artifacts\release\v<version>`, вместе с файлом `SHA256SUMS.txt`.
У версионных параметров разные роли, и перед каждым релизом они проверяются на согласованность:
`InformationalVersion` — публичная версия для GitHub, используется в тегах и именах файлов, например `3.2`
`Version` — версия сборки .NET, например `3.2.0`
`FileVersion` и `AssemblyVersion` — четырёхчастная версия для Windows и WinGet, например `3.2.0.0`
Если эти значения не совпадают между собой, скрипт останавливается.
Публикация в WinGet
Скрипт для WinGet подходит и для первой публикации пакета, и для последующих обновлений:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Publish-WinGet.ps1
```
Он считывает версию проекта, проверяет публичный релиз на GitHub и обе архитектуры, генерирует манифесты, запускает `winget validate`, при желании выполняет локальный тест установки и удаления, и может сам отправить PR через WingetCreate.
Для автоматического обновления после публикации релиза на GitHub:
```powershell
.\scripts\Publish-WinGet.ps1 -Version 3.3 -NonInteractive -InstallTest -Submit
```
Что нужно заранее:
актуальный клиент Windows Package Manager
актуальный пакет `Microsoft.WingetCreate`
настроенная авторизация GitHub в WingetCreate для отправки PR
> WinGet рассматривает Omen Gaming Hub Unlocker как портативное приложение. Команда `winget uninstall` удаляет исполняемый файл и алиас команды, но не отменяет ранее применённые изменения в Windows. Если вы хотите убрать все настроенные правила файрвола, записи hosts, изменения служб, задач и автозагрузки — сначала запустите **Disable scripts**, а потом уже удаляйте программу.

🧩 Решение проблем
SmartScreen: «Windows защитила ваш компьютер»
Портативные программы без цифровой подписи, скачанные с GitHub, могут вызывать предупреждение SmartScreen:
Нажмите Подробнее → Выполнить в любом случае
OMEN всё равно на секунду появляется при входе в систему
UWP-приложения могут кратко инициализироваться при входе в систему или проверке обновлений. Если службы и задачи отключены (и, опционально, заблокирована сеть), короткое появление окна не обязательно значит, что OMEN связался с сервером.
Если вы искали что-то из этого:
«OMEN Gaming Hub недоступен в моём регионе»
«OMEN Gaming Hub неверный регион»
«OMEN Gaming Hub регион заблокирован»
«HP OMEN Gaming Hub страна не поддерживается»
«OMEN Gaming Hub обход через VPN»
Эта программа сделана именно для такого сценария: загрузка → VPN → сами открываете OMEN.
